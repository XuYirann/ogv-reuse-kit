# 数据字典

本包的数据来自原项目 app/data；打包日期为 2026-10-30，不代表数据已更新到该日。全部数据文件及顶层字段见 ../catalog.json。

## 长视频收入：可直接使用

文件：data/longVideoRevenue.json。来源字段 source 保留原文。

| 数组 | 指标 | 单位 | 模板 |
|---|---|---|---|
| membership | 会员收入 | 亿元 | 分平台堆叠柱 |
| advertising | 广告收入 | 亿元 | 分平台堆叠柱 |
| members | 会员数 | 亿 | 分平台折线 |
| arppu | 会员 ARPPU | 元/月 | 分平台折线 |

每条记录包含 period（两位年份加季度，如 26Q2），以及 腾讯视频、爱奇艺、优酷视频、芒果TV 四个字段，值为数字或 null。每个数组的覆盖范围以实际记录为准。

会员数：原复盘说明腾讯视频、爱奇艺为日均会员数，芒果 TV、优酷为季度末会员数。原复盘 ARPPU 注释为季度会员总收入/期末会员数/3；本包保留原始测算数值，不依据 members 数组重新计算，因为分平台分母口径存在差异。

## 后台到前端的映射

原项目线上读取 `/ogv/api/public/categories/revenue`，响应包含 datasets 数组，每个数据集含 key 和 rows。未发布时接口可能返回 404。本包无需访问该接口。

| 后台 key | 前端数组 | 原项目转换 |
|---|---|---|
| revenue_1_1 | membership | 会员收入字段转季度；各平台数值除以 100 |
| revenue_1_2 | advertising | 列1年份与列2季度拼接；数值直接使用 |
| revenue_1 | members | 列1转季度；各平台数值除以 100 |
| revenue_3___arppu | arppu | ARPPU 元 - 每月字段转季度；数值直接使用 |

平台别名和精确转换见 reference/components/usePublishedRevenueData.ts。data 中的数据已完成转换，不能再次除以 100。接口地址是原站相对路径；接入新站需配置实际主机、访问权限及跨域策略。

## 其他数据集

用户规模、时长、重合、动画、剧集、综艺、电影、纪录片数据已打包，用于后续拓展。catalog 中标记为 reference_requires_metric_review。使用前阅读 JSON 和对应 reference/components 文件，确认单位、分母、榜单范围及数据来源。不能默认其格式与收入相同。
