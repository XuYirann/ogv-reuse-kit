# 分析报告图表：同比标注规范

本文件定义三种可复用的同比表现方式。涉及同比柱状图时，先选择一种模式，再按该模式实现，不混用几何逻辑。

## 快速选择

| 模式名 | 适用对象 | 核心表现 |
|---|---|---|
| `总计同比顶括号` | 整根柱子的合计同比 | 两根柱顶之间的折线括号、末端箭头、居中气泡 |
| `子项同比右箭头` | 堆叠柱中某一个子项的同比 | 两条水平虚线、柱右侧垂直差值箭头、箭头右侧气泡 |
| `右侧图例同比` | 多个子项需要同时解释，图右侧有空间 | 色块、子项名、下一行同比；移除底部图例 |

## 共用规则

- 默认比较同季度同比，例如 26Q2 对 25Q2，不比较相邻季度。
- 先把数据坐标转换为像素坐标，再绘制 annotation。ECharts 使用 `convertToPixel`；不要猜固定像素位置。
- annotation 使用独立 graphic 层，设置高于柱形的 `zlevel` 和 `z`。虚线必须画在柱面前方。
- chart 首次 `setOption` 后，在下一帧绘制 annotation。窗口或容器 resize 后，先 `chart.resize()`，再重新计算 annotation。
- 同比文字使用强调色，但字号比柱内具体数值小 1 级。常规图建议柱内 9-10px、同比 7-8px。
- 气泡为白底、细灰边、红字；不要用大面积红底。
- 气泡与箭头保持 4-8px 间距，不要推到容器最右侧。
- 柱顶合计数不能被箭头、折线或气泡遮挡。
- 如果同一图出现多个同比，先判断是否应改用 `右侧图例同比`，不要堆叠多套箭头。

## A. 总计同比顶括号

### 适用场景

比较两根完整柱子的合计变化，例如 25Q2 总播放 508 亿到 26Q2 411 亿。

### 几何结构

1. 取去年柱顶坐标 `(xPrev, yPrev)`。
2. 取今年柱顶坐标 `(xNow, yNow)`。
3. 在两者较高的柱顶上方预留 24-40px，得到 `yTop`。
4. 画折线：去年柱顶上方起点 -> `yTop` -> 横跨到今年柱 -> 垂直到今年柱顶上方。
5. 在末端画指向今年柱顶的箭头。
6. 气泡放在顶端水平线的中点。

### 必须满足

- 箭头指向整根柱子的顶部，不指向某个堆叠子项。
- 两端与柱顶留出 16-28px，保证柱顶合计数清晰。
- 气泡文字只写百分比，例如 `-19%`，除非用户明确要求前缀。

### ECharts 实现骨架

```ts
const prev = chart.convertToPixel({ xAxisIndex: 0, yAxisIndex: 0 }, [prevIndex, prevTotal]);
const now = chart.convertToPixel({ xAxisIndex: 0, yAxisIndex: 0 }, [nowIndex, nowTotal]);
const yTop = Math.min(prev[1], now[1]) - 36;

const points = [
  [prev[0], prev[1] - 22],
  [prev[0], yTop],
  [now[0], yTop],
  [now[0], now[1] - 22],
];
```

用 `graphic.polyline` 画折线，用 `graphic.polygon` 画末端箭头，用 `graphic.rect + graphic.text` 画气泡。

### 用户指令

最短指令：

> 这个图的整体同比用「总计同比顶括号」。

完整指令：

> 25Q2 和 26Q2 的总计同比用「总计同比顶括号」：折线放在两根柱顶上方，气泡居中，箭头指向 26Q2 柱顶，不要挡住柱顶合计数。

## B. 子项同比右箭头

### 适用场景

只比较堆叠柱中的一个子项，例如热播剧 TOP50 从 179 亿降到 152 亿。

### 几何结构

1. 取去年子项上边界坐标 `(xPrev, yPrev)`。
2. 取今年子项上边界坐标 `(xNow, yNow)`。
3. 在今年柱右侧预留固定 x 坐标 `xArrow`。建议为 `xNow + 24-36px`。
4. 从去年边界画水平虚线到 `xArrow`。
5. 从今年边界画水平虚线到 `xArrow`。
6. 在 `xArrow` 上画一根连接两条虚线的垂直箭头，箭头指向今年值。
7. 气泡紧贴箭头右侧，间距 4-8px。

### 必须满足

- 必须同时有去年、今年两条水平虚线。只有一条虚线不构成差值表达。
- 虚线从柱子中心或柱内开始，覆盖在柱面前方，不能被柱子遮挡。
- 垂直箭头固定在最右柱外，不画在柱体内部。
- 气泡不能通过 `max()` 被推到容器最右侧；应优先使用 `xArrow + gap`，仅在越界时向左 clamp。
- 气泡文字只写百分比，例如 `-15%`。
- 同一图需要表示两个以上子项同比时，优先改用 `右侧图例同比`。

### ECharts 实现骨架

```ts
const prev = chart.convertToPixel({ xAxisIndex: 0, yAxisIndex: 0 }, [prevIndex, prevValue]);
const now = chart.convertToPixel({ xAxisIndex: 0, yAxisIndex: 0 }, [nowIndex, nowValue]);
const xArrow = now[0] + 28;
const bubbleX = Math.min(xArrow + 6, chart.getWidth() - bubbleWidth - 6);

const guides = [
  { x1: prev[0], y1: prev[1], x2: xArrow, y2: prev[1] },
  { x1: now[0], y1: now[1], x2: xArrow, y2: now[1] },
];
```

两条 guide 使用虚线；箭头使用红色实线和三角形箭头。整个 group 使用高 `zlevel`，确保覆盖柱体。

### 用户指令

最短指令：

> 热播剧 TOP50 的同比用「子项同比右箭头」。

完整指令：

> 热播剧 TOP50 的 25Q2-26Q2 同比用「子项同比右箭头」：两个数值边界各引一条虚线到最右柱外，同一 x 坐标画垂直箭头，`-15%` 气泡紧贴箭头右侧。

## C. 右侧图例同比

### 适用场景

多个堆叠子项需要同时说明同比，而且图右侧空间充足。例如 TOP10 与 11-50 各自的同比。此时它们是分类说明，不需要多套差值箭头。

### 视觉结构

每个子项使用一个两行标签：

```text
■  TOP10
   同比 -5%

■  11-50
   同比 -24%
```

色块与柱段颜色完全一致。标签的垂直位置对齐最新一期柱中对应子项的中心。

### 必须满足

- 删除底部图例，避免同一信息出现两次。
- 第一行：色块 + 子项名称；第二行：`同比 ±N%`。
- 正增长和负增长均可用强调色；如需区分，可正增长用正文色、负增长用红色，但整份报告必须一致。
- 子项标签按堆叠顺序排布，并尽量与最新柱的对应色块中心对齐。
- 标签之间不足 28px 时，做上下错位或使用固定最小间距；不要让文字或色块重叠。
- 右侧为标签预留 110-160px，不要挤压柱子到难以阅读。
- 总计同比若仍需要，可继续使用 `总计同比顶括号`，它与右侧分类标签表达不同层级。

### ECharts 实现骨架

```ts
const segmentCenterValue = lowerStackTotal + segmentValue / 2;
const point = chart.convertToPixel(
  { xAxisIndex: 0, yAxisIndex: 0 },
  [latestIndex, segmentCenterValue],
);

const labelX = chart.getWidth() - 110;
const labelY = point[1];
```

用 `graphic.rect` 画色块，两个 `graphic.text` 分别画名称和同比。不要为这些标签加气泡边框。

### 用户指令

最短指令：

> TOP10 和 11-50 用「右侧图例同比」。

完整指令：

> 删除底部图例，TOP10 和 11-50 使用「右侧图例同比」：右侧放对应颜色方块和名称，下一行写同比，位置与 26Q2 对应柱段对齐；总计同比仍用柱顶括号。

## 组合用法

常见组合：

- 整体 + 单一重点子项：`总计同比顶括号` + `子项同比右箭头`
- 整体 + 多个子项：`总计同比顶括号` + `右侧图例同比`
- 只有子项变化：单独使用 `子项同比右箭头`
- 多个分类均需解释：单独使用 `右侧图例同比`

不要在一张图里同时使用 `子项同比右箭头` 和 `右侧图例同比` 表达同一批子项。

## 发布前检查

- [ ] 同比比较的是同季度，而非环比。
- [ ] 总计括号指向柱顶，且不遮挡合计数。
- [ ] 子项右箭头有两条虚线，箭头位于最右柱外。
- [ ] 子项虚线位于柱面前方。
- [ ] 气泡距箭头 4-8px。
- [ ] 同比字号比柱内数值小 1 级。
- [ ] 右侧图例的色块与柱段颜色一致。
- [ ] 右侧图例启用时，底部图例已删除。
- [ ] 多个标签没有重叠。
- [ ] resize 后 annotation 重新计算。
