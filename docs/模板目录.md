# 模板目录与迁移入口

## 已可独立生成

| ID | 模板 | 输入 | 实现 |
|---|---|---|---|
| quarterly-stacked-bar | 季度堆叠柱图 | 季度、1 至 4 个可相加系列、数值、单位、来源 | templates/revenue.html + scripts/render_chart.py |
| quarterly-line | 季度多系列折线 | 季度、1 至 4 个系列、数值、单位、来源 | 同上 |

柱图支持总计同比顶括号与右侧图例同比，折线支持右侧图例同比。子项同比右箭头有规范与原始实现参考，目前通用模板未集成该模式。

## 原复盘组件参考

以下文件位于 reference/components/。这些是可供 AI 阅读和抽取的实现，不承诺单文件可运行。

| 场景 | 入口 |
|---|---|
| 收入构成与会员趋势 | RevenueStructureSection.tsx、ShortDramaRevenueCharts.tsx |
| 用户规模、时长、重合 | DauChart.tsx、DurationStackedCharts.tsx、AudienceOverlapChart.tsx |
| 动画趋势与项目份额 | AnimationTrend.tsx、AnimationProjectShare.tsx |
| 横屏剧集趋势、效率及榜单 | HorizontalDramaTrend.tsx、HorizontalShortDramaTrend.tsx、HorizontalDramaEfficiency.tsx、HorizontalDramaTopSeries.tsx |
| 综艺趋势和榜单 | VarietyTrend.tsx、VarietyTopSeries.tsx |
| 电影趋势、榜单、份额及票房 | FilmTrend.tsx、FilmTop10.tsx、FilmProjectShare.tsx、FilmBoxOffice.tsx |
| 纪录片榜单 | DocumentaryRanking.tsx |
| 同比图形和响应式布局 | chartBrackets.ts、chartResponsive.ts |
| 后台字段到前端数据 | usePublishedRevenueData.ts、usePublishedPlatformData.ts、usePublishedCategoryReports.ts |

迁移时先读组件 imports，定位 data 文件、单位、数据整理及 ECharts option。将业务数据与 option 分开，去除报告正文、线上 hook 和 React 生命周期依赖，再补独立渲染和 PNG 导出。图片或平台 logo 若未随包提供，应另行取得实际素材，或使用平台名称文本。不能把缺少依赖的源码称为现成独立模板。
