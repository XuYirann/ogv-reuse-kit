# OGV 季度复盘：页面层级与图表密度规范

本规范用于 OGV 市场复盘 HTML。核心原则是：**结论是主体，图表是证据**。图表应帮助读者快速验证判断，而不是抢占结论的视觉权重。

## 固定字号

| 内容层级 | 桌面字号 | 说明 |
|---|---:|---|
| 品类标题（如“横屏剧集”） | 20px | Part 02 下单个品类的一级标题 |
| 品类分析点标题（如“横屏长剧大盘趋势”） | 18px | 每个品类内部的分析模块标题 |
| 图表标题 | 15px | 所有现有及新增图表统一 |
| 结论正文 / 可编辑结论 | 14px | 所有结论框、结论 tab、洞察文本统一 |
| 图表辅助控件 | 8-9px | 时间范围、开始/结束时间；不应抢标题 |
| 数据来源 / 交互提示 | 9-10px | 放在图表底部 |

不要为了填满空间放大图表标题或结论。标题靠层级、间距和位置区分，不靠夸张字号。

## 结论与图表关系

- 每个分析点由“序号 + 18px 标题 + 14px 结论”组成一个完整的结论模块。
- 结论占满内容宽度并与分析点标题左侧对齐；使用轻量左侧强调线和底部分隔线，不用厚重、四边封闭的大卡片。
- 左侧强调线启用后，结论正文开头不再添加短横线、圆点等重复引导符号。
- 结论正文使用非对称内边距：左侧约 17px、右侧约 6px；左侧留出强调线后的呼吸空间，右侧避免无效空耗。
- 结论内部只保留紧凑的阅读留白，不用大面积上下左右边距制造模块感。
- 证据图放在结论之后，用细边框形成独立元素。
- 桌面端证据图组相对结论左右各内缩约 14px，让“判断”在视觉上覆盖“证据”；窄屏取消内缩，避免压缩绘图区。
- 结论到证据图组的垂直间距约 14px，使两者形成一个连续的“先判断、后验证”阅读单元。
- 图表标题只描述指标，不重复模块标题或结论。
- 双图并排时，优先让结论和两张图在一个常见桌面视口内形成完整阅读单元。
- 图表高度宁可偏紧凑并保留留白，也不要高到一屏看不完整。

## 趋势图头部

趋势图的固定头部结构按可用宽度区分：

```text
DAU / MAU 双栏图：
左：图表眉题 + 15px 图表标题      右：近 1 年｜近 5 年｜开始 [月份]｜结束 [月份]

时长趋势图：
左：图表眉题 + 15px 图表标题      右：近 1 年｜近 5 年｜开始 [季度]｜结束 [季度]
```

- 时间控制区放在标题同一视觉行的右侧，不单独占一整行。
- DAU / MAU 双栏图和时长趋势图的四组控件都必须在同一行，按钮、标签与输入值统一使用 9px。
- 控件高度约 26-28px，字号 8-9px。
- 窄屏允许头部换行，控制区改为占满宽度；不要强行压缩到不可操作。

## 图表页脚

固定页脚结构：

```text
左：悬停 / 缩放 / 筛选提示      右：数据来源
```

- 数据来源不得占据图表头部的高价值位置。
- 数据来源与交互提示放在同一行底部；窄屏可自然换行。
- 若没有复杂交互，提示可缩短，但仍保留数据来源。

## 高度基线

- 两张并排的 DAU / MAU 趋势图：绘图区约 350px。
- 单张横向构成图：绘图区约 330-360px。
- 通栏时长趋势图：主图约 260-290px；次要补充图约 210-230px。
- 高度应按信息密度微调，但不得仅为了“更有存在感”而放大。

## 用户指令

最短指令：

> 按「OGV 季度复盘规范」排版。

完整指令：

> 按「OGV 季度复盘规范」：结论 14px、图表标题 15px、品类分析点标题 18px、品类标题 20px；结论优先、图表紧凑。DAU / MAU 与时长趋势图的四组时间控件都放在标题右侧同一行；数据来源移到底部并与交互提示同一行。
