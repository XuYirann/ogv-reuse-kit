# 数据到图片的执行路径

用户文件 → AI 识别字段与口径 → 标准 JSON → render_chart.py → 独立 HTML → 浏览器渲染 → PNG。

## 标准输入

完整示例见 examples/custom-data.json。必要字段：

| 字段 | 含义 |
|---|---|
| title | 图标题 |
| template | quarterly-stacked-bar 或 quarterly-line |
| unit | 统一单位 |
| source | 真实来源文字 |
| snapshot | 数据版本或导出日期；未知时明确写未提供 |
| series | 1 至 4 个不同系列名 |
| rows | 每行含 period 和每个系列的数字或 null |
| quarter | all 或 Q1/Q2/Q3/Q4；可省略，默认 all |

period 为 25Q2 等唯一季度。长表先按季度透视成宽表；只有用户确认是可加明细时才聚合重复记录。百分比需确认是 0 至 1 还是 0 至 100，先统一口径。现成柱图用于可相加绝对值，比例应另行调整合计逻辑。

## 生成

在仓库根目录运行：

```sh
python3 scripts/render_chart.py examples/custom-data.json --output output/chart.html
```

该脚本验证字段，将标准输入映射到模板的 META、ORDER 和 ogv-data，并嵌入本地 ECharts。输出文件可独立分享，无需服务器。数据仍在本机，无后台上传步骤。

包内收入数据结构为多个指标数组，需挑选 membership 等数组作为 rows，明确 unit、series 和来源，转换成上述标准输入。原专用示例仍可用 scripts/build_example.py 更新。

## 由 AI 直接导出图片

使用环境已有的浏览器自动化工具打开生成的 HTML。待图表渲染后，点击「下载 PNG」，将下载结果保存到 output/。或者在具有页面执行能力的浏览器自动化环境中，获取：

```javascript
const element = document.getElementById('chart');
const instance = echarts.getInstanceByDom(element);
const png = instance.getDataURL({type: 'png', pixelRatio: 2, backgroundColor: '#fff'});
```

将 data URL 中的 Base64 数据解码保存为 PNG。此代码在图表页面上下文运行，不能在普通 Node 进程里直接执行。无需为此调用线上数据库。

导出后打开 PNG，确认标题、来源、同比与合计均可读。默认 2080×1080；不同尺寸需同步调整容器、grid、右侧标注和页脚位置。浏览器工具不可用时交付 HTML，明确尚未生成 PNG，并给出手动下载操作。

## 验收重点

手算一个同比核对；确认缺失值未转零；新数据与原始行数、数值一致；选择空系列有提示；标题与注释不遮挡。长来源或长系列名可能需要换行调整。用户需要超过 12 个季度时，修改模板的 slice(-12) 并检查横轴密度。
