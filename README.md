# 让 AI 复用图表，把数据变成图片

这个包适合两种情况：你看中了现成图表，想换数据或改样式；你手里有一份数据，希望 AI 帮你选图并直接出图。

下载并解压整个仓库，把文件夹交给能读取本地文件的 AI。告诉它「先读 AGENTS.md」。你负责说明想表达什么，AI 负责识别数据、确认口径、调用模板和生成结果。

## 场景一：复刻已有图表，或者在它的基础上修改

当前有 **2 种可直接生成的图表模板**，共同使用 `templates/revenue.html` 的渲染逻辑：

| 模板 | 适合表达 | 默认样式 | 你需要提供什么 |
|---|---|---|---|
| 季度堆叠柱图 `quarterly-stacked-bar` | 每季度总量及各业务/平台构成 | 柱顶合计、总计同比顶括号、右侧各系列同比 | 季度、系列名、数值、共同单位、来源 |
| 季度多系列折线图 `quarterly-line` | 不同平台/业务的指标变化 | 分系列折线、右侧同比、缺失处断线 | 季度、系列名、数值、共同单位、来源 |

可以先打开 `examples/revenue-standalone.html` 看效果。其中会员收入、广告收入使用柱图；会员数、ARPPU 使用折线图。它们是两种模板的四个应用例子。

**直接对 AI 说：**

> 先读这个文件夹的 AGENTS.md。我想复用季度堆叠柱图，使用包里的会员收入数据，只看历年 Q2。保留现有配色、总计同比顶括号和右侧同比。请生成 HTML 和 PNG 图片。

**想修改时继续说：**

> 在刚才这张图上，只保留腾讯视频和爱奇艺，把标题改成“两平台会员收入变化”，导出高清 PNG。

> 把这份数据换成季度折线图，保留单位和来源，缺失的季度不要补零。

也可以明确提出字体、颜色、尺寸、标签、时间范围或排序的要求。AI 会根据模板修改代码并检查图片。当前默认输出 2080 × 1080 PNG；自定义尺寸需要 AI 调整布局。

包中还收录了原复盘的用户规模、时长、重合结构、动画、剧集、综艺、电影和纪录片组件源码。它们列在 `docs/模板目录.md`，可让 AI 参考迁移，尚未全部做成独立可运行模板。

## 场景二：把自己的数据给 AI，让它直接出图

把 Excel、CSV、JSON 或粘贴的表格交给 AI，同时告诉它以下信息。文件里已经写清楚的内容不用再重复。

| 信息 | 例子 |
|---|---|
| 想表达什么 | 比较两项业务收入构成及同比变化 |
| 哪些列是什么 | 季度、业务名称、收入 |
| 单位及口径 | 万元；每季度收入；两项业务互不重叠 |
| 数据范围 | 25Q2 和 26Q2，业务 A 和业务 B |
| 来源 | 内部经营报表，2026-10-30 导出 |
| 想要的结果 | 堆叠柱图，PNG；也保留 HTML 便于修改 |

**可以这样说：**

> 请读这个图表包的 AGENTS.md。附件是季度收入数据，单位万元。我想看业务 A 和业务 B 的收入构成及 26Q2 同比，用季度堆叠柱图，沿用模板样式。来源写“内部经营报表”。请检查字段和缺失值，把数据转换成模板需要的格式，直接生成 PNG，并附上可修改的 HTML。有影响计算的缺失信息再问我。

AI 会先核对数据、说明采用的字段和口径，再把数据映射到模板。你不需要自己写 JSON 或运行命令。如果当前 AI 环境不能执行代码或打开浏览器，它会明确说明，并给出完整 HTML；你双击打开后可点击「下载 PNG」。

你也可以先说「我不确定用什么图，请根据这份数据给我建议」。当前自动映射支持 **季度、1 至 4 个系列、非负数或缺失值**。月度、负值、超过四个系列、占比口径等需求，需要 AI 调整模板，不能直接硬套。

## 一次交互应该得到什么

- 最终 PNG 图片，以及可继续修改的 HTML。
- 简短说明：用了哪些数据、单位、时间范围、同比基期。
- 如果有缺失值、口径差异或未能完成导出，AI 会指出具体影响。

同一张图可以连续修改。直接描述要改的部分即可，无需重新解释全部数据。

## 仓库为什么能让 AI 完成这些事

| 文件 | AI 用它做什么 |
|---|---|
| `AGENTS.md` | 理解如何引导操作者、何时提问、怎样完成交付 |
| `docs/模板目录.md` | 选择模板，找到参考组件和依赖 |
| `docs/数据映射与出图.md` | 把用户数据转成统一输入，并执行出图流程 |
| `scripts/render_chart.py` | 将标准输入映射到图表，生成独立 HTML |
| `templates/revenue.html` | 实际绘图、同比、筛选、PNG 导出代码 |
| `docs/同比标注规范.md`、`docs/复盘视觉规范.md` | 复刻和修改时保持图表风格 |
| `data/`、`catalog.json` | 可复用数据快照及其索引 |
| `reference/components/` | 原复盘的图表实现及后台字段转换参考 |

无需运行生产后台。已有快照可以直接画图，新数据由 AI 读取并映射。若要接入原后台，可参照 `docs/数据字典.md` 和 `reference/components/usePublishedRevenueData.ts`。

现有业务数据是本地复盘静态快照，打包于 2026-10-30，不代表在线数据库最新内容。仓库包含实际业务数据，适合按团队分享范围放入私有 GitHub 仓库。下载后保留完整目录；发给 AI 的私有链接需要其环境有访问权限。
